# Mengxu Jiang Academic Homepage

This repository contains Mengxu Jiang's academic homepage, based on the [academicpages](https://github.com/academicpages/academicpages.github.io) template.

## Publish on GitHub Pages

Configured homepage URL:

```text
https://mengxujiang.github.io
```

Push this folder to the GitHub Pages repository. In GitHub, open `Settings` -> `Pages` and publish from the `main` branch.

## Main files

- `_config.yml`: site title, URL, sidebar profile, email, GitHub, Google Scholar.
- `_pages/about.md`: one-page homepage content.
- `_publications/`: publication entries.

## Local preview

If Ruby and Bundler are installed:

```bash
bundle install
bundle exec jekyll serve
```
